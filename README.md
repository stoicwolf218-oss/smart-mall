# 智能商城系统（Python 版 + 支付网关 + Tkinter 图形界面）

> 由原 C 语言「智能商城系统 · 深度修复版 v2」（`shop_v2.c`）忠实翻译为 Python，
> 并在此基础上**新增支付网关**、**Tkinter 图形界面**，可直接运行使用。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

---

## ✨ 功能特性

### 1. 商品管理（管理员）
- 新增 / 修改 / 删除 / 搜索商品
- 保质期自动计算与**批量过期检测**
- 清空零库存商品、清空过期商品
- 上架 / 下架、库存管理

### 2. 用户系统
- 注册（新用户自动赠送 10 元优惠券）、登录、修改密码
- 余额充值、优惠券发放
- 累计消费升级 **VIP**（满 500 元升 VIP 并赠送 50 元券）
- 每满 100 元消费自动返 10 元优惠券

### 3. 🆕 支付网关
- 支持四种支付方式：**余额支付 / 支付宝 / 微信支付 / 银行卡**
- 模拟第三方支付网关：生成唯一交易号、校验余额 / 卡号、记录每笔交易流水
- 管理员可在后台查看「支付流水」

### 4. 🆕 Tkinter 图形界面
- 登录 / 注册窗口
- 买家面板：选购商品、购物（选支付方式）、订单查询、AI 推荐、个人中心
- 管理员面板：商品管理、用户管理、销量预测、灰度发布、备份恢复、支付流水

### 5. 智能功能
- **销量预测**：基于历史订单的平均日销量外推未来销量
- **AI 推荐**：根据用户历史购买记录推荐相似 / 热门商品
- **灰度发布**：按 `user_id % 100` 控制灰度比例（默认 10%）
- 小猫情绪系统 🐱（购买成功开心、失败难过）

## 💳 支付网关设计

```
买家下单 → 选择支付方式 → 支付网关
                              ├─ 余额支付：校验账户余额，不足则失败
                              ├─ 支付宝 / 微信：生成模拟支付二维码（演示直接成功）
                              └─ 银行卡：校验卡号长度（≥12 位）后放行
                              ↓
                          生成唯一交易号 (TXN...)
                              ↓
                          写支付流水 (data/payments.json)
                              ↓
                      支付成功 → 扣券/扣余额 → 减库存 → 生成订单 → 累计消费
```

每笔交易（成功或失败）都会写入 `data/payments.json`，管理员可在「数据 / 支付 / 系统」页查看流水。

## 📊 数据存储

数据以 **JSON** 格式保存在 `data/` 目录，每次写入采用「写临时文件 + 原子替换」，
避免中途崩溃导致数据损坏（对应原 C 版的 `_tmp.txt` + `rename()` 安全写入）。

- `products.json` — 商品
- `users.json` — 用户
- `orders.json` — 订单
- `counter.json` — 订单号计数器
- `payments.json` — 支付流水

管理员后台提供**一键备份 / 恢复**（备份到 `latest_backup/`）。
