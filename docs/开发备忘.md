# 开发备忘

## 本地启动

```bash
python app.py
```

默认端口 `8000`，需要换端口时：

```bash
PORT=9000 python app.py
```

## 常用检查

- 运行冒烟测试：`python smoke_test.py`
- 运行单元测试：`python -m unittest test_checkout.py`
- 清理运行期数据：删除 `data/` 与 `latest_backup/`（会重置商品、用户与订单）

## 目录约定

- `static/`：前端静态资源
- `data/`：运行期自动生成的 JSON 数据，不纳入版本管理
- `latest_backup/`：管理员后台备份目录，不纳入版本管理

## 提交前自检

1. 本地启动后页面可正常打开
2. 下单、支付、登录主流程无报错
3. 未把 `data/` 下的真实数据提交进仓库
